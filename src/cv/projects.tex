  {github.com/nmdra/ERPBridge}

  {Go, MCP, SQLite, Redis, Prometheus, Docker Compose}

\begin{itemize}
  \item Designed and built a non-invasive declarative control plane that transforms registered ERP HTTP APIs and OpenAPI operations into typed MCP tools without modifying ERP source code or existing API contracts.

  \item Created a bounded ERPNext evaluation covering five operations and 80 retained smoke and boundary records for tool generation, authorization, versioning, and reconciliation.
